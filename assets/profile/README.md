# Profile artwork

The Habit lettering is original, drawn specifically for this profile from
custom vector paths and shapes, not a font or outlined stock glyphs.
Apple's handwritten activation-screen “hello” inspired the friendly, flowing
direction only; no Apple artwork, font, or third-party asset was copied.

`habit-light.svg` and `habit-dark.svg` share the same geometry and differ only
in their palette and surface description. Both are self-contained static SVGs
with no external resources. The light version's opaque surface also serves
as the fallback when theme-aware picture sources are unsupported.
