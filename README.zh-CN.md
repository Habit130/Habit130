这里是 Habit。遇到感兴趣的想法，就做些小实验边实践边探索，也借助 AI 帮忙。

### 在做的项目

- **LLM 辅助输入探索** — 在 [Rime/Squirrel](https://github.com/rime/squirrel) 基础上，通过 [squirrel](https://github.com/Habit130/squirrel) 与 [librime-llm-rerank](https://github.com/Habit130/librime-llm-rerank) 探索结合上下文的候选词重排序，仍处于实验阶段。
- **[CV research practice](https://github.com/Habit130/cv-research-practice)** — 建设中的 CV 科研实践 scaffold，串联论文选读、代码复现、实验记录与对比分析、报告写作。
- **[CropGuard](https://github.com/Habit130/MiniGPT-4)** — 基于 [MiniGPT-v2](https://github.com/Vision-CAIR/MiniGPT-4) 的作物图像 visual question answering 应用，不替代专业诊断。
